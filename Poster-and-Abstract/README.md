# Poster and Abstract

## Project Title
**Trie-Based Predictive Text and Autocomplete System Using C++**

## Overview
This project explores how a Trie data structure can be used to implement predictive text and autocomplete functionality. The application is developed in C++ and provides a menu-driven interface for managing and searching words using prefix matching.

This project demonstrates how data structures can support efficient word retrieval and how Trie-based systems relate to applications in predictive text and natural language processing.

## Project Poster
The completed poster summarizes the project objectives, Trie data structure, main operations, C++ implementation, autocomplete demonstration, complexity analysis, testing results, applications, and future improvements.

**Poster File:** `Trie_Autocomplete_Poster.png`

## Abstract
The project implements a menu-driven application in C++ using a Trie, a tree-based data structure that stores words character by character. The application supports inserting words, searching for words, generating autocomplete suggestions from a given prefix, displaying stored words, and removing words.

The program includes input validation and demonstrates how Trie operations can efficiently retrieve words that share common prefixes. For example, entering the prefix `comp` can return `compute`, `computer`, and `computing`.

This project demonstrates the relationship between data structures and applications such as predictive text and natural language processing. The implementation uses prefix matching rather than a machine-learning model or contextual prediction system.

**Abstract File:** `Trie_Autocomplete_Abstract.docx`

## Main Features
- Insert new words into the Trie.
- Search for exact words.
- Generate autocomplete suggestions based on prefixes.
- Display stored vocabulary.
- Remove words from the Trie.
- Validate user input and handle invalid entries.
- Analyze time and space complexity.

## Technologies Used
- C++
- Trie data structure
- Prefix matching
- Object-oriented programming concepts
- Basic concepts related to artificial intelligence and natural language processing
